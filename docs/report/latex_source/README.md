## Compile

Requires TeX Live with `biblatex` (Debian/Ubuntu: `texlive-bibtex-extra`), `pgfplots`, `tabu` and `tocloft`. The
template selects the BibTeX backend, so Biber is not needed.

```
latexmk -pdf main.tex
# or: pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Overleaf: upload the folder and compile with pdfLaTeX.

**Result here (2026-11-01):** compiles without errors to 68 pages (TeX Live 2023). The two end-of-log notices
("There were undefined references", biblatex's "Please (re)run BibTeX") come from the template's BibTeX backend for
biblatex and also appear in a five-line test document; every citation and cross-reference in the PDF resolves. Four
overfull boxes under 3 pt remain (two in the template's CO–PO and bonafide pages, two in Table 4.1).

## Changes to the template

The original template folder is unchanged; this is a copy.
* New title and placeholders. The title page and the declaration use `\thesisguide` instead of names hard-coded in
  the template (the declaration named a different guide from the title page).
* Added packages: booktabs, longtable, tabularx, multirow, xcolor, pgfplots, amsthm. `\headheight` is set to 15 pt
  (fancyhdr asked for 14.5 pt), and `\emergencystretch` lets lines with long file paths break.
* The sample code appendix is replaced by seven excerpts of the project source (Appendix A). "BIBILOGRAPHY" is now
  "REFERENCES". "MINI PROJECT-II" is now "MINI PROJECT-I". The running header is set in a smaller size so the long
  title fits on one line.
